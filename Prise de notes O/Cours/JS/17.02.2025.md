Exemple d'évènement :
```
document.getElementById("btn").addEventListener("click",function(){
    document.querySelector("h1").innerText="Bonjour";
});
```
---->  Le bouton va changer le texte h1 en "Bonjour".  

.innerText ---> Seulement le Texte
.innerHTML ---> comprend aussi des balises. (donc peut exécuter en fonction des balise ex: un lien href)

```
document.getElementById("btn").addEventListener("click",function(){
    let h1 = document.querySelector("h1");
    h1.innerText = "Bonjour";
    h1.classList.toggle("error");
});
```

----> Le bouton va changer le texte en bonjour, et exécuter le css lié a la class "error"
.toggle = Exécute si existe, et enlève si n'existe pas (au reclick)


*display = afficher



### Condition des caractères :

email :
```PHP
^[A-Za-z0-9.\-_\+]+@[A-Za-z0-9.\-]+[.]{1}[A-Za-z0-9]{2,}$
```

^ = Commence par
le + veux dire pas de limite du nombre de caractère
le {2,} veux dire qu'il y a minimum 2 caractère, et pas de max
le \ sert a specifier un caractèere ( ici le - et le + pour qu'ils compte bien comme des caractères)
Le $ = fini par
{1} = un seul element


"i" veut dire majuscule = minuscule et inversement
