### Dates :

```PHP
$date = new DateTime('2025-02-01');
echo $date->format('Y-m-d H:i:s'); // affiche : 2025-02-01 00:00:00
```

autres exemples :

- comparer les dates :
```PHP
$date1 = new DateTime('2025-02-01');
$date2 = new DateTime('2025-02-02');

if ($date1 < $date2) {
echo "la date 1 est anterieure à la date 2";
} elsif ($date1 > $date2) {
echo "la date 1 est posterieure à la date 2";
} else {
echo "les deux dates sont identiques";
}
```
